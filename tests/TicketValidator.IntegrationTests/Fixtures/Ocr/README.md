# OCR Fixture

`sharp-ticket.png` is a fictitious, high-contrast ticket used by
`TesseractOcrServiceTests`. It contains no personal or real business data and
uses the visible word `TICKETVALIDATOR` as a stable OCR assertion.

`rotated-ticket.png` is the same ticket rotated 90 degrees. `blurred-ticket.png`
is generated by downscaling and upscaling the original image. In
`difficult-date-ticket.png`, only the central part of the date is downscaled
and upscaled to make it harder to read.

`rotated-180-ticket.png` and `rotated-270-ticket.png` are further orthogonal
rotations of the same fictitious source ticket. The four orientation fixtures
also document whether OSD reaches its technical confidence threshold; the
service preserves the original bytes when it does not.

`distant-ticket.png` places the original ticket in the center of a larger
canvas, so it occupies 25% of the image area without adding blur or noise.
`tilted-ticket.png` rotates the complete original ticket by 10 degrees without
cropping it.
